1. 按已确认设计更新 SKILL.md 的触发说明、必要追问、默认输出顺序与 Word 导出邀请。
2. 添加 references/interview-preparation.md，定义三版口语稿、重点题详解、扩展题、反问及事实校验。
3. 更新 README 能力说明、交互示例与指定仓库安装地址。
4. 添加使用合成材料的完整报告导出测试，检查各模块、重点题与追问在 DOCX 中保留。
5. 校验技能及引用，运行全部脚本测试；审阅完整差异，确认没有个人材料。
6. 同步已安装技能并核对内容哈希；再次校验与测试已安装副本。
7. 提交并发布更新分支，为目标仓库创建 PR；核验 PR 文件与本地版本一致，报告目标合并状态。
